# tooltip-detector

수술 영상에서 수술도구를 분할하고 수술 도구의 끝부분을 탐지하는 딥 러닝 모델을 학습한다.

현재 파이프라인은 다음 단계로 구성된다.

1. 영상분할 모델을 생성한다.
2. 각 이미지별로 수술도구의 영역과 수술도구의 끝부분 위치가 기록된 학습 데이터를 읽는다.
3. 영상분할 모델을 학습 및 평가한다.

## 요구 사항

- Python `3.12` 이상
- 프로젝트 의존성 설치
- GPU 추론을 사용할 경우 CUDA가 동작하는 PyTorch 환경

의존성 설치 예시:

```bash
uv sync
```

또는 가상환경에서 직접 설치 후 사용한다.
