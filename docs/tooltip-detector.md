# Tooltip Detector GUI 가이드

학습된 `TooltipDetector` 모델을 이용해 복강경 수술 영상 프레임에서 수술도구 팁 위치를 실시간으로 추론하고 시각화하는 인터랙티브 GUI 도구다.

## 개요

`scripts/tooltip-detector.py`는 두 가지 모드를 지원한다.

| 모드        | 설명                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **dataset** | `data/dataset/` 내 train / val / test 스플릿의 프레임을 순서대로 탐색. GT 어노테이션과 예측 결과를 비교하고 누적 평가 지표를 실시간으로 확인한다. |
| **file**    | 임의의 이미지 파일을 직접 열어 팁 탐지 결과만 확인한다. GT 어노테이션 없음.                                                                       |

## 실행

```bash
run tooltip-detector          # Linux / macOS
run.bat tooltip-detector      # Windows
```

모델 경로 지정:

```bash
run tooltip-detector --model data/models/gradient-seg/monai/best.pt --data-root data/dataset
```

`gaussian-tip`으로 학습한 모델 로드:

```bash
run tooltip-detector --target-mode gaussian-tip
```

## 인수

| 인수            | 기본값                                           | 설명                                                                                |
| --------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------- |
| `--model-type`  | `monai`                                          | 모델 아키텍처 (`monai` / `monai_mini`), GUI의 `Model` 드롭다운으로도 전환 가능      |
| `--target-mode` | `gradient-seg`                                   | 로드할 체크포인트의 타겟 생성 방식(초기값). GUI의 `Target` 드롭다운으로도 전환 가능 |
| `--model`       | `data/models/<target-mode>/<model-type>/best.pt` | 학습된 모델 가중치 파일 경로                                                        |
| `--data-root`   | `data/dataset`                                   | 데이터셋 루트 디렉터리                                                              |

### 행 1 — 탐색 컨트롤

| 요소                  | 설명                                                                      |
| --------------------- | ------------------------------------------------------------------------- |
| `Mode` 드롭다운       | `dataset` / `file` 모드 전환                                              |
| `Split` 드롭다운      | 스플릿 전환 (dataset 모드에서만 활성)                                     |
| `Model` 드롭다운      | `monai` / `monai_mini` 전환, 선택한 타입의 `best.pt` 재로드               |
| `Target` 드롭다운     | `gradient-seg` / `gaussian-tip` 전환, 선택한 타겟 모드의 `best.pt` 재로드 |
| `Open Image…` 버튼    | 임의 이미지 파일 열기 (file 모드에서만 활성)                              |
| `<-` / `->` 버튼      | 이전 / 다음 프레임 (dataset 모드)                                         |
| `Rand` 버튼           | 무작위 프레임 이동                                                        |
| 인덱스 입력 + `Enter` | 지정 인덱스로 바로 이동                                                   |
| `/ N` 표시            | 현재 스플릿의 전체 프레임 수                                              |

### 행 2 — 추론 파라미터

| 요소                  | 범위        | 기본값 | 설명                                                   |
| --------------------- | ----------- | ------ | ------------------------------------------------------ |
| `Threshold` 슬라이더  | 0.05 ~ 0.95 | 0.50   | 히트맵 피크 탐지 임계값. 높일수록 고신뢰도 피크만 탐지 |
| `NMS radius` 슬라이더 | 5 ~ 50 px   | 20 px  | 이웃 피크 억제 반경. 낮추면 인접 팁을 분리 탐지 가능   |

슬라이더를 움직이면 현재 프레임을 즉시 재추론하여 결과를 갱신한다. 누적 통계는 변경되지 않는다.

### 행 3 — 이미지 패널

두 패널은 항상 552 × 360 px (원본 736 × 480의 75%)로 표시된다.

#### 왼쪽 패널 — Original

원본 이미지 위에 GT 어노테이션과 예측 결과를 오버레이한다.

| 시각 요소        | 설명                                          |
| ---------------- | --------------------------------------------- |
| 색상 바운딩 박스 | 도구별 GT 바운딩 박스 (도구 인덱스별 색상)    |
| 색상 원 + 십자선 | GT 팁 위치 마커                               |
| 빨간 X           | 예측 팁 위치 마커                             |
| 노란 선          | 각 GT 팁과 가장 가까운 예측 팁을 잇는 오차 선 |

도구 색상 순서:

| 인덱스 | 색상             |
| ------ | ---------------- |
| 0      | 초록 (`#00FF00`) |
| 1      | 주황 (`#FF8800`) |
| 2      | 하늘 (`#00AAFF`) |
| 3      | 보라 (`#FF00FF`) |
| 4+     | 순환 반복        |

#### 오른쪽 패널 — Heatmap

모델이 출력한 채널 1에 sigmoid를 적용한 값(0~1)을 hot 컬러맵으로 색상화하여 원본 이미지 위에 블렌딩(alpha=0.65)한다. 히트맵 값이 0인 배경 픽셀은 원본 이미지 그대로 표시된다.

| 히트맵 값  | 색상 |
| ---------- | ---- |
| 0.0 (배경) | 원본 |
| ~0.33      | 빨강 |
| ~0.67      | 노랑 |
| 1.0 (팁)   | 흰색 |

오른쪽 패널에도 빨간 X (예측 피크 마커)가 오버레이된다.

### 행 4 — 프레임 정보 바

현재 프레임의 추론 결과를 텍스트로 표시한다.

**dataset 모드:**

```text
File: doctor_250620_084707_00000042   GT tips: 2   Predicted: 2
  tip[0] GT=(154,176)  pred=(151,179)  dist=3.2px  conf=0.921  ✓ hit@10px
  tip[1] GT=(186,240)  pred=(183,244)  dist=5.0px  conf=0.876  ✓ hit@10px
```

**file 모드:**

```text
[File mode]  Detected tips: 2
(151,179) conf=0.921  (183,244) conf=0.876
```

### 행 5 — 탐색 바 (Seekbar)

수평 슬라이더로 데이터셋 내 임의 위치로 빠르게 이동한다. 슬라이더를 드래그하면 150 ms 디바운싱 후 해당 인덱스로 이동한다.

### 행 6 — 누적 평가 통계 패널

dataset 모드에서 GT 팁이 있는 프레임을 탐색할 때마다 누적 평가 지표를 실시간으로 갱신한다.

| 지표      | 설명                                            |
| --------- | ----------------------------------------------- |
| Frames    | 누적 탐색한 GT 팁 보유 프레임 수                |
| GT tips   | 누적 GT 팁 수                                   |
| Missed    | 예측 후보 없음으로 탐지 실패한 GT 팁 수 및 비율 |
| Mean dist | 매칭된 팁의 평균 픽셀 거리                      |
| Median    | 매칭된 팁의 중앙값 픽셀 거리                    |
| P90       | 픽셀 거리 90 백분위수                           |
| Hit@10px  | 예측-GT 거리 ≤ 10 px인 팁 비율                  |
| Hit@20px  | 예측-GT 거리 ≤ 20 px인 팁 비율                  |
| Hit@50px  | 예측-GT 거리 ≤ 50 px인 팁 비율                  |

`Reset Stats` 버튼을 누르면 누적 통계가 초기화된다. 스플릿을 전환해도 초기화된다.

## 조작 방법

### 키보드 단축키

| 키  | 동작               |
| --- | ------------------ |
| `←` | 이전 프레임        |
| `→` | 다음 프레임        |
| `R` | 무작위 프레임 이동 |

### 모드 전환

`Mode` 드롭다운에서 `dataset` ↔ `file` 전환 시 동작:

- `dataset`로 전환: 마지막으로 선택한 스플릿의 0번 프레임으로 이동
- `file`로 전환: 패널이 초기화되고 `Open Image…` 버튼이 활성화됨

## 추론 흐름

```text
프레임 선택
    │
    ▼
SurgicalToolDataset[idx]  →  HWC uint8 RGB 이미지
    │
    ▼
_eval_transform()          →  CHW float32 텐서 (정규화)
    │
    ▼
TooltipDetector.forward()  →  (1, 2, H, W) 출력
    │
    ▼
sigmoid(output[:, 1])      →  (H, W) 히트맵 float32 [0, 1]
    │
    ▼
find_peaks(heatmap, threshold, nms_radius)
    │  1. threshold 이상 픽셀 이진화
    │  2. 연결요소 분석
    │  3. 각 컴포넌트에서 최대값 픽셀 선택
    │  4. NMS: 반경 내 낮은 피크 제거
    ▼
peaks: [(x, y, confidence), ...]  값 내림차순 정렬
    │
    ▼
GT 팁과 매칭 → 유클리드 거리 계산 → 누적 통계 갱신
```

## 설계 상세

### 클래스 구조

```text
TooltipDetectorApp (tk.Tk)
├── _load_model()          모델 로드 (오류 시 None, 경고 출력)
├── _infer()               단일 이미지 추론 → (heatmap, peaks)
├── _build_ui()            위젯 초기화
├── _load_split()          스플릿 데이터셋 로드 및 0번 프레임 표시
├── _render_dataset_frame()  dataset 모드 렌더링
├── _render_file_frame()   file 모드 렌더링
├── _stats_update()        누적 통계 갱신
├── _stats_str()           통계 텍스트 생성
└── _refresh_stats_display()  통계 패널 갱신
```

### 주요 상수

| 상수              | 값           | 설명                             |
| ----------------- | ------------ | -------------------------------- |
| `PANEL_W`         | 552 px       | 이미지 패널 표시 너비 (736×0.75) |
| `PANEL_H`         | 360 px       | 이미지 패널 표시 높이 (480×0.75) |
| `_HIT_THRESHOLDS` | (10, 20, 50) | hit-rate 계산 임계 거리 (px)     |
| `_PRED_COLOR`     | `#FF3333`    | 예측 팁 X 마커 색상              |
| `_LINE_COLOR`     | `#FFFF00`    | GT → 예측 오차 선 색상           |

### 이미지 스케일링

원본 이미지는 736 × 480 px이며, 패널에는 552 × 360 px(75%)로 축소하여 표시한다. 추론은 항상 원본 해상도에서 수행하며, 팁 좌표 정보도 원본 해상도 기준이다.

file 모드에서는 열린 이미지를 먼저 736 × 480으로 리사이즈한 뒤 추론하여 좌표가 표시 좌표와 일치하도록 한다.

### 슬라이더 디바운싱

탐색 바는 슬라이더 이동 시 `after(150, ...)` 방식으로 150 ms 디바운싱을 적용한다. 슬라이더를 빠르게 드래그해도 추론이 과도하게 호출되지 않는다.

## 주의 사항

- 모델 파일이 없거나 로드에 실패하면 경고 메시지를 출력하고 히트맵 없이(0 값) 실행된다. GUI는 정상 표시되나 추론 결과는 없다.
- dataset 모드 누적 통계는 탐색한 프레임만 집계한다. 스플릿 전체를 평가하려면 `run eval-model`을 사용한다.
- file 모드에서는 GT 어노테이션 없이 예측만 표시되므로 누적 통계 패널이 갱신되지 않는다.
