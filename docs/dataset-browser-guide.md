# 데이터셋 브라우저 가이드

데이터셋의 이미지, 어노테이션, 거리 기반 히트맵을 시각적으로 탐색하는 GUI 도구다.

## 실행

```bash
run dataset-browser                     # Linux / macOS (cholec80 train으로 시작)
run.bat dataset-browser                 # Windows
```

다른 데이터셋·스플릿으로 시작:

```bash
run dataset-browser --dataset erop --split val
```

## 인수

| 인수          | 기본값         | 설명                                                      |
| ------------- | -------------- | --------------------------------------------------------- |
| `--dataset`   | `cholec80`     | 시작 데이터셋 이름 (`erop` / `cholec80`). GUI의 `Dataset` 드롭다운으로도 전환 가능 |
| `--data-root` | `data/dataset` | `<dataset-name>/` 서브디렉터리를 담는 루트 디렉터리        |
| `--split`     | `train`        | 시작 스플릿 (`train` / `val` / `test`)                     |

### 파일 목록

화면 왼쪽에 현재 스플릿의 파일 목록을 표시한다.

- **File**: 파일 베이스명 (확장자 제외)
- **Tools**: 해당 프레임에 레이블링된 수술도구 수 (어노테이션 JSON의 `annotations` 항목 수)

행을 클릭하면 그 프레임으로 바로 이동하고, 목록에 포커스가 있을 때는 `↑` / `↓` 키로 한 프레임씩 이동한다. 다른 방법(`←` `→`, 슬라이더 등)으로 프레임을 옮겨도 목록의 선택 행이 따라가며 화면 안으로 스크롤된다.

도구 수는 JSON 파일을 읽어야 알 수 있으므로, 목록은 창이 뜬 뒤 백그라운드에서 2,000행씩 채워진다. 목록 제목의 `(표시 행 수 / 전체 프레임 수)`에서 표시 행 수 뒤에 `+`가 붙어 있으면 아직 채우는 중이다.

### Tools 필터

`Tools` 드롭다운(`All` / `0` / `1` / `2` / `3` / `4` / `5+`, 기본값 `All`)으로 파일 목록을 레이블링된 도구 수로 거른다. `5+`는 도구가 5개 이상인 프레임만 표시한다.

- 필터를 바꿨을 때 현재 프레임이 조건에 맞지 않으면 첫 번째로 맞는 프레임으로 이동한다.
- `All`이 아닐 때 `◄` `►` 버튼과 `←` `→` 키는 필터를 통과한 프레임 사이에서만 이동하고, `Rand`도 그중에서 고른다.
- 하단 슬라이더와 인덱스 입력은 필터와 관계없이 스플릿 전체를 대상으로 한다.
- 스플릿이나 데이터셋을 바꿔도 선택한 필터는 유지된다.

### 표시 방식 탭

이미지 패널 위의 탭으로 표시 방식을 고른다. 이미지는 한 번에 한 장만 표시하며, 고른 탭은 프레임을 이동해도 유지된다.

| 탭                            | 표시 내용                                   |
| ----------------------------- | ------------------------------------------- |
| `Original`                    | 원본 이미지                                 |
| `Original + Annotations`      | 원본 + 바운딩 박스 + 팁 마커                |
| `Original + Distance Heatmap` | 원본 위에 거리 기반 히트맵을 컬러맵으로 블렌딩 |

#### Original + Annotations

- **바운딩 박스**: 도구별로 다른 색상으로 표시
- **팁 마커**: 원(circle) + 십자선(crosshair)으로 팁 위치 표시

도구 색상은 인덱스 순서로 8색을 순환 적용한다:

| 인덱스 | 색상             |
| ------ | ---------------- |
| 0      | 초록 (`#00FF00`) |
| 1      | 주황 (`#FF8800`) |
| 2      | 하늘 (`#00AAFF`) |
| 3      | 보라 (`#FF00FF`) |
| 4      | 노랑 (`#FFFF00`) |
| 5      | 빨강 (`#FF4444`) |
| 6      | 청록 (`#44FFFF`) |
| 7      | 분홍 (`#FF44FF`) |
| 8+     | 순환 반복        |

#### Original + Distance Heatmap

거리 기반 히트맵을 hot 컬러맵으로 색상화하여 원본 이미지 위에 블렌딩한다.

| 히트맵 값  | 색상               |
| ---------- | ------------------ |
| 0.0 (배경) | 원본 이미지 그대로 |
| ~0.33      | 빨강               |
| ~0.67      | 노랑               |
| 1.0 (팁)   | 흰색               |

히트맵 생성 방법은 [dataset-guide.md](dataset-guide.md)의 "학습 타겟 생성 방법" 항목을 참고한다.

### 정보 바

현재 프레임의 메타정보를 표시한다. 이미지 패널과 같은 폭에 3줄 높이로 고정된 읽기 전용 텍스트 상자이므로, 팁 좌표가 길어져도 창 크기는 바뀌지 않고 줄바꿈된 뒤 오른쪽 스크롤바로 나머지를 볼 수 있다. 텍스트는 마우스로 선택해 복사할 수 있다.

```text
File: video01_00000075   Tools: 2   heatmap: [0.000, 1.000]
tip[0]=(154, 176)  tip[1]=(186, 240)
```

- `File`: 파일 베이스명 (확장자 제외)
- `Tools`: 프레임 내 수술도구 수
- `heatmap`: 히트맵 값의 최솟값과 최댓값 범위
- `tip[i]`: 각 도구의 팁 픽셀 좌표

### 탐색 바 (Seekbar)

하단의 수평 슬라이더로 데이터셋 내 임의 위치로 빠르게 이동할 수 있다. 슬라이더를 드래그하면 150 ms 디바운싱 후 해당 인덱스의 프레임을 표시한다.

## 조작 방법

### 컨트롤 패널

| 컨트롤              | 동작                             |
| ------------------- | -------------------------------- |
| `Dataset` 드롭다운  | 데이터셋 전환 (`erop` / `cholec80`), 전환 시 현재 스플릿을 새 데이터셋에서 다시 로드 |
| `Split` 드롭다운    | 스플릿 전환 (train / val / test) |
| `Tools` 드롭다운    | 파일 목록을 도구 수로 필터링 (All / 0〜4 / 5+) |
| `◄` / `►` 버튼      | 이전 / 다음 프레임 (필터 적용 시 목록 내에서) |
| `Rand` 버튼         | 무작위 프레임 이동 (필터 적용 시 목록 내에서) |
| 파일 목록 클릭      | 해당 프레임으로 이동             |
| 표시 방식 탭        | Original / Annotations / Distance Heatmap 전환 |
| 인덱스 입력 + Enter | 지정 인덱스로 이동               |
| 하단 슬라이더       | 임의 위치로 빠른 이동            |

### 키보드 단축키

| 키  | 동작               |
| --- | ------------------ |
| `←` | 이전 프레임 (필터 적용 시 목록 내에서) |
| `→` | 다음 프레임 (필터 적용 시 목록 내에서) |
| `R` | 무작위 프레임 이동 (필터 적용 시 목록 내에서) |
| `↑` / `↓` | 파일 목록에 포커스가 있을 때 이전 / 다음 행 |

## 스플릿 전환

`Split` 드롭다운에서 스플릿을 선택하면 해당 스플릿의 첫 번째 프레임(인덱스 0)으로 이동한다. `Dataset` 드롭다운을 전환해도 마찬가지로 현재 스플릿의 0번 프레임으로 이동한다. 인덱스와 슬라이더 범위가 선택된 데이터셋·스플릿의 샘플 수에 맞게 갱신되고, 파일 목록도 새 스플릿으로 다시 채워진다. 이때 `Tools` 필터가 `All`이 아니고 0번 프레임이 조건에 맞지 않으면 첫 번째로 맞는 프레임으로 이동한다.

`erop` 데이터셋 기준 스플릿별 샘플 수 (`cholec80`은 구축 완료 후 별도 기재):

| 스플릿 | 샘플 수 |
| ------ | ------- |
| train  | 108,424 |
| val    | 36,140  |
| test   | 36,142  |
