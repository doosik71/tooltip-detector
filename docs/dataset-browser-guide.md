# 데이터셋 브라우저 가이드

데이터셋의 이미지, 어노테이션, 거리 기반 히트맵을 시각적으로 탐색하는 GUI 도구다.

## 실행

```bash
run dataset-browser          # Linux / macOS
run.bat dataset-browser      # Windows
```

다른 스플릿으로 시작:

```bash
run dataset-browser --split val
```

## 인수

| 인수          | 기본값         | 설명                                   |
| ------------- | -------------- | -------------------------------------- |
| `--data-root` | `data/dataset` | 데이터셋 루트 디렉터리                 |
| `--split`     | `train`        | 시작 스플릿 (`train` / `val` / `test`) |

### 왼쪽 패널 — Original + Annotations

원본 이미지 위에 어노테이션 정보를 오버레이한다.

- **바운딩 박스**: 도구별로 다른 색상으로 표시
- **팁 마커**: 원(circle) + 십자선(crosshair)으로 팁 위치 표시

도구 색상은 인덱스 순서로 순환 적용된다:

| 인덱스 | 색상             |
| ------ | ---------------- |
| 0      | 초록 (`#00FF00`) |
| 1      | 주황 (`#FF8800`) |
| 2      | 하늘 (`#00AAFF`) |
| 3      | 보라 (`#FF00FF`) |
| 4+     | 순환 반복        |

### 오른쪽 패널 — Distance Heatmap

거리 기반 히트맵을 hot 컬러맵으로 색상화하여 원본 이미지 위에 블렌딩한다.

| 히트맵 값  | 색상               |
| ---------- | ------------------ |
| 0.0 (배경) | 원본 이미지 그대로 |
| ~0.33      | 빨강               |
| ~0.67      | 노랑               |
| 1.0 (팁)   | 흰색               |

히트맵 생성 방법은 [dataset-guide.md](dataset-guide.md)의 "학습 타겟 생성 방법" 항목을 참고한다.

### 정보 바

현재 프레임의 메타정보를 표시한다.

```text
File: doctor_250620_084707_00000042   Tools: 2   heatmap: [0.000, 1.000]
tip[0]=(154, 176)  tip[1]=(186, 240)
```

- `File`: 파일 베이스명 (확장자 제외)
- `Tools`: 프레임 내 수술도구 수
- `heatmap`: 히트맵 값의 최솟값과 최댓값 범위
- `tip[i]`: 각 도구의 팁 픽셀 좌표

### 탐색 바 (Seekbar)

하단의 수평 슬라이더로 데이터셋 내 임의 위치로 빠르게 이동할 수 있다. 슬라이더를 드래그하면 150 ms 디바운싱 후 해당 인덱스의 프레임을 표시한다.

## 조작 방법

### 컨트롤 패널

| 컨트롤              | 동작                             |
| ------------------- | -------------------------------- |
| `Split` 드롭다운    | 스플릿 전환 (train / val / test) |
| `◄` / `►` 버튼      | 이전 / 다음 프레임               |
| `Rand` 버튼         | 무작위 프레임 이동               |
| 인덱스 입력 + Enter | 지정 인덱스로 이동               |
| 하단 슬라이더       | 임의 위치로 빠른 이동            |

### 키보드 단축키

| 키  | 동작               |
| --- | ------------------ |
| `←` | 이전 프레임        |
| `→` | 다음 프레임        |
| `R` | 무작위 프레임 이동 |

## 스플릿 전환

`Split` 드롭다운에서 스플릿을 선택하면 해당 스플릿의 첫 번째 프레임(인덱스 0)으로 이동한다. 인덱스와 슬라이더 범위가 선택된 스플릿의 샘플 수에 맞게 갱신된다.

| 스플릿 | 샘플 수 |
| ------ | ------- |
| train  | 108,424 |
| val    | 36,140  |
| test   | 36,142  |
