# 데이터셋 가이드

수술도구 분할 및 팁(tip) 탐지를 위한 학습 데이터셋의 구조와 포맷을 설명한다.

## 디렉터리 구조

```text
data/dataset/
├── annotation/
│   ├── train/   # 108,424개 JSON
│   ├── val/     #  36,140개 JSON
│   └── test/    #  36,142개 JSON
├── images/
│   ├── train/   # 108,424개 PNG
│   ├── val/     #  36,140개 PNG
│   └── test/    #  36,142개 PNG
└── segmentation/
    ├── train/   # 108,424개 PNG
    ├── val/     #  36,140개 PNG
    └── test/    #  36,142개 PNG
```

총 180,706 프레임. train : val : test ≈ 60 : 20 : 20.

## 파일 명명 규칙

모든 파일은 동일한 베이스명을 공유한다.

```text
{세션ID}_{프레임번호:08d}.{ext}
```

| 구성 요소    | 설명                                                | 예시                   |
| ------------ | --------------------------------------------------- | ---------------------- |
| `세션ID`     | `doctor_YYMMDD_HHMMSS` 형식의 촬영 세션 식별자      | `doctor_250620_084707` |
| `프레임번호` | 원본 영상에서의 0-기준 프레임 인덱스 (8자리 0-패딩) | `00000030`             |

예시: `doctor_250620_084707_00000030.json / .png`

## 촬영 세션

데이터는 5개의 독립적인 수술 영상 세션에서 추출됐다.

| 세션 ID                | train  | val    | test   |
| ---------------------- | ------ | ------ | ------ |
| `doctor_250620_084707` | 14,406 | 4,802  | 4,802  |
| `doctor_250620_131843` | 16,249 | 5,416  | 5,416  |
| `doctor_250702_084355` | 11,165 | 3,721  | 3,722  |
| `doctor_250702_101536` | 46,193 | 15,397 | 15,398 |
| `doctor_250723_094100` | 20,411 | 6,804  | 6,804  |

각 세션은 세 스플릿 모두에 등장한다. 스플릿 분할은 시간 순서 기반(temporal split)으로, 같은 세션의 앞부분이 train에, 뒷부분이 val·test에 속한다.

프레임은 원본 영상에서 약 10프레임(초당 약 3프레임) 간격으로 샘플링됐다.

## images

- **포맷**: PNG, RGB (3채널)
- **해상도**: 736 × 480 px (전 프레임 동일)
- 수술 현장을 촬영한 복강경(laparoscope) 영상 프레임이다.

## segmentation

- **포맷**: PNG, 그레이스케일 (L 모드)
- **해상도**: 736 × 480 px (images와 동일)
- **픽셀값**: `0` = 배경, `255` = 수술도구 영역

images와 1:1 대응. annotation에 수술도구가 없는 프레임의 마스크는 전부 0이다.

## annotation

- **포맷**: JSON
- **필드 구조**:

```json
{
  "image":  "doctor_250620_084707_00000030.png",
  "width":  736,
  "height": 480,
  "annotations": [
    {
      "bbox": { "x": 63, "y": 136, "width": 92, "height": 51 },
      "tip":  { "x": 154, "y": 176 }
    },
    {
      "bbox": { "x": 186, "y": 225, "width": 465, "height": 198 },
      "tip":  { "x": 186, "y": 240 }
    }
  ]
}
```

| 필드                 | 설명                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| `image`              | 대응하는 이미지 파일명                                                       |
| `width`, `height`    | 이미지 해상도 (항상 736, 480)                                                |
| `annotations`        | 프레임 내 수술도구 목록 (없으면 빈 배열 `[]`)                                |
| `annotations[].bbox` | 수술도구의 경계 상자 — 좌상단 좌표 `(x, y)` 와 `width`, `height` (픽셀 단위) |
| `annotations[].tip`  | 수술도구 끝부분(팁)의 픽셀 좌표 `(x, y)`                                     |

좌표계: 좌상단이 원점 `(0, 0)`, x축이 오른쪽, y축이 아래쪽.

### 프레임당 수술도구 수 분포 (train)

| 도구 수       | 프레임 수 | 비율   |
| ------------- | --------- | ------ |
| 0 (도구 없음) | 15,616    | 14.4 % |
| 1             | 46,458    | 42.9 % |
| 2             | 32,635    | 30.1 % |
| 3             | 10,495    | 9.7 %  |
| 4             | 2,416     | 2.2 %  |
| 5+            | 804       | 0.7 %  |

약 86 %의 프레임에 수술도구가 하나 이상 등장한다.

## annotation ↔ segmentation 대응

annotation의 `annotations` 배열이 비어있지 않은 프레임에는 거의 항상 segmentation 마스크가 존재한다. 약 1 % 미만의 프레임에서 annotation과 segmentation 간 불일치가 관찰됐다(라벨링 오류 또는 경계 케이스).

## 학습 타겟 생성 방법

본 프로젝트에서는 단순 이진 분할 대신 **거리 기반 히트맵(heatmap)** 을 학습 타겟으로 사용한다.

1. segmentation 마스크의 각 도구 화소에 대해 가장 가까운 팁까지의 거리를 계산한다.
2. 팁 화소: 값 `1.0`
3. 마스크 내에서 팁으로부터 가장 먼 화소: 값 `0.0`
4. 그 사이 화소: 거리에 반비례하여 선형 보간

$$
\text{target}(p) = 1 - \frac{\min_{t \in \text{tips}} \|p - t\|}{\max_{q \in \text{mask}} \min_{t \in \text{tips}} \|q - t\|}
$$

배경 화소(마스크 외부)의 타겟값은 `0.0`이다. 프레임에 도구가 없으면 전체 타겟이 `0.0`이다.
